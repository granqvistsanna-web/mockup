# Mockup

Drop screenshots in, get device mockups out: browser window, desktop monitor, laptop, tablet, phone, a desktop + phone pair, or a three-screen spread, on a solid, gradient, blurred or image background. Exports PNG at 1–3x or copies to the clipboard. Everything runs in the browser, nothing is uploaded.

Part of the [Toolbox](https://granqvistsanna-web.github.io/). One `index.html`, styled with [Pumice](https://granqvistsanna-web.github.io/pumice/).

- House style templates: rimmed screens, a dark glow or blur, windows running off the bottom, a raised phone trio, and an optional title and tag.
- Marketplace templates follow top-selling Framer thumbnails (see `research/`). Everything is 4:3; export at 2x for 3200 × 2400.
- Tall full-page captures work: Scroll picks which part shows.
- Frames are drawn on a canvas, so they stay sharp at any export size.
- Settings are remembered per browser; screenshots are not.
